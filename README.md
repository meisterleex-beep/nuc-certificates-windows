# Установка TLS-сертификатов НУЦ Минцифры в Windows

Скачайте [Install-NucCertificates.exe](https://github.com/meisterleex-beep/nuc-certificates-windows/releases/latest/download/Install-NucCertificates.exe) и дважды щёлкните по файлу, чтобы установить сертификаты для текущего пользователя. Если Windows запросит подтверждение добавления доверенного корневого сертификата, проверьте его данные в диалоге и подтвердите установку.

EXE содержит сертификаты и работает без интернета, на Windows с .NET Framework 4.8. Цифровой подписи у EXE нет. Комплект предназначен для сайтов, использующих TLS-сертификаты НУЦ Минцифры.

## Запуск из терминала

```powershell
.\Install-NucCertificates.exe --install            # Установить для текущего пользователя
.\Install-NucCertificates.exe --check              # Проверить доступность для текущего пользователя
.\Install-NucCertificates.exe --install --machine  # Установить для всех пользователей (терминал администратора)
.\Install-NucCertificates.exe --check --machine    # Проверить хранилища компьютера
```

При повторной установке утилита пропускает сертификаты, которые уже видны в выбранном хранилище. Windows также показывает сертификаты компьютера в хранилищах текущего пользователя. Если выпуск находится вне срока действия, утилита его пропускает. Для установки нужен действующий корневой и хотя бы один действующий выпускающий сертификат. Если импорт прервался, после устранения причины можно запустить ту же команду повторно.

Коды завершения для автоматизации:

- `0` — операция выполнена успешно.
- `1` — ошибка установки или проверки, либо неверные параметры.
- `2` — в режиме проверки отсутствует хотя бы один действующий сертификат из комплекта.

## Состав комплекта

Сертификаты взяты из [Windows-архива Госуслуг](https://gu-st.ru/content/lending/windows_russian_trusted_root_ca.zip) со страницы [поддержки российских сертификатов](https://www.gosuslugi.ru/crt). Файлы в папке `certificates` приведены к формату DER. Утилита сверяет SHA‑256 всех встроенных сертификатов перед открытием хранилищ.

| Файл | Хранилище Windows | SHA‑256 (DER) |
| --- | --- | --- |
| `Russian_Trusted_Root_CA.cer` | `Root` — доверенные корневые центры сертификации | `D26D2D0231B7C39F92CC738512BA54103519E4405D68B5BD703E9788CA8ECF31` |
| `Russian_Trusted_Sub_CA.cer` | `CA` — промежуточные центры сертификации | `BBBDE2103E790B999EC62BD03CF625A5A2E7C316E10AFE6A490EEDEAD8B3FD9B` |
| `Russian_Trusted_Sub_CA_2024.cer` | `CA` — промежуточные центры сертификации | `2155785036C900DBB5F1BB2A1569C80C55595BD6BF94867A29BBDDBC7D88A3F2` |

## Сборка

Запустите `Build.ps1` в PowerShell. Скрипт использует компилятор C# из установленного .NET Framework и создаёт `Install-NucCertificates.exe` в папке проекта.
